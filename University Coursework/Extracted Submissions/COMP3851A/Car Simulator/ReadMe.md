# Unity Track Editor Controls
* Left Click - Place Car/ Place Track
* Right Click - Complete Polygon

* z - Undo
* x - Reset
* s - Save Workspace (Requires a track and car to be placed first)
* l - Load Workspace
* c - Place Car
* v - Place Track
* e - Rotate Car AntiClockwise
* r - Rotate Car Clockwise

* Tab - Cycle through mode selection (Place Car / Place Track)

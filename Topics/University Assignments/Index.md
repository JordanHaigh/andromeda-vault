# University Assignments

A navigable catalogue of preserved university coursework. Each project has an individual page with context and links to representative submitted files. Full project trees remain under `University Coursework/Extracted Submissions/`. Descriptions are based on archive names and file contents; they provide historical context rather than current production guidance.

## Preserved submissions

The ZIP bundles are not part of this repository layout. Their extracted project trees are preserved under `University Coursework/Extracted Submissions/`, with per-project file counts and links on the assignment pages.

## Notes

The linked section describes Go documentation comments. A comment immediately before a top-level declaration documents that declaration; package and command comments form the primary documentation surface. The broader guide stresses Go-specific idioms, machine formatting with gofmt, concise package naming, and documentation that describes exported APIs.

The current Go documentation warns that Effective Go dates from 2009 and does not cover later language and ecosystem changes such as generics and modules. Treat it as guidance for core-language idiom and pair it with current reference material for modern Go.

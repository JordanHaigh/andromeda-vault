# Installation Guides

## What it does

This folder contains the Installation Guides resource from the cosmos master collection. The source implementations define the exact input contract, edge cases, and variant used here. The notes below identify those files and give a starting point for comparing implementations; verify behavioral details against the code before relying on them.

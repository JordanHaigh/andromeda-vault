# K Centers

## What it does

Selects k facility centers to minimize the maximum distance from any point to its nearest center. The standard farthest-first greedy algorithm repeatedly chooses the point farthest from existing centers and is a 2-approximation in metric spaces. Complexity depends on how distances are represented.

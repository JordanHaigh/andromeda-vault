# Huffman Coding

## What it does

Builds an optimal prefix code for symbol frequencies by repeatedly combining the two least-frequent trees in a priority queue. The resulting variable-length code minimizes weighted path length among prefix codes. A heap gives O(n log n); ties may yield different but equally optimal codes.

# Activity Selection

## What it does

Selects the maximum number of mutually compatible intervals by sorting activities by finish time and repeatedly choosing the earliest-finishing activity that starts after the last chosen one. The greedy rule is optimal for unweighted interval count; weighted variants need dynamic programming.

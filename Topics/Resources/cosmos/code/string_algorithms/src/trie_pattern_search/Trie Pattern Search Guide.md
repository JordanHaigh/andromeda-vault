# Trie Pattern Search

## What it does

A trie stores strings by shared prefixes. Pattern search follows one edge per character; wildcard variants branch at wildcard positions and can visit many nodes. The structure is useful for prefix queries and dictionaries, with memory proportional to the number of stored character edges.

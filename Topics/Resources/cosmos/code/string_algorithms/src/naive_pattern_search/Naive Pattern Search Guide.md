# Naive Pattern Search

## What it does

The straightforward matcher compares the pattern at every possible text offset. It needs no preprocessing, uses O(1) extra space, and takes O((n−m+1)m) worst-case time. It is easy to verify and can be competitive for short patterns or small inputs.

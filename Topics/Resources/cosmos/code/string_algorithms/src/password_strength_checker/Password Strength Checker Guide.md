# Password Strength Checker

## What it does

Estimates how resistant a password is to guessing. A useful checker reasons about length, character diversity, common-password dictionaries, and predictable patterns; raw character-class counts alone can overstate strength. Never log submitted passwords, and treat any score as a heuristic rather than a security guarantee.

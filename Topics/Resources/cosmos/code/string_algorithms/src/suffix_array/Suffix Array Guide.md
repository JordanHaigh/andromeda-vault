# Suffix Array

## What it does

A suffix array stores the starting positions of all suffixes in lexicographic order. It supports compact substring search by binary search and is a foundation for text indexes and longest-common-prefix analysis. Naive construction is O(n² log n); specialized algorithms improve this, so consult the implementation for its method.

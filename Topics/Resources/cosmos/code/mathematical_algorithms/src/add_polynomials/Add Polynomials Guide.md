# Add Polynomials

## What it does

Adds two polynomials by combining coefficients of equal powers, usually in O(m+n) time for coefficient arrays. Sparse representations should merge terms by exponent and remove zero coefficients. Confirm whether the code assumes dense, ascending-order coefficient storage.

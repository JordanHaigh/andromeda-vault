# Babylonian Method

## What it does

Approximates √S with repeated averaging: xₙ₊₁=(xₙ+S/xₙ)/2. This is Newton’s method applied to x²−S=0 and converges quadratically near the positive root. Guard negative inputs, zero, stopping tolerance, and iteration limits.

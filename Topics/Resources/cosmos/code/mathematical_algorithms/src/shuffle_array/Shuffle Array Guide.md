# Shuffle Array

## What it does

See Fisher–Yates: each iteration swaps a position with a uniformly selected position in the remaining suffix. This yields a uniform permutation when each draw is independent and unbiased. This implementation is distinct from other shuffle entries; compare their random-number APIs and bounds.

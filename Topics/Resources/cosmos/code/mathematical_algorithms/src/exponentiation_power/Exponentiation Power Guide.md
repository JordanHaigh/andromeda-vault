# Exponentiation Power

## What it does

Computes xⁿ by exponentiation by squaring: square the base while halving the exponent and multiply it into the result for set bits. This takes O(log n) multiplications. Negative exponents, zero-to-zero, modular arithmetic, and overflow are separate edge cases.

# Multiply Polynomial

## What it does

Multiplies coefficient sequences by convolution: each pair of terms contributes to the coefficient whose exponent is the sum of their exponents. Dense multiplication is O(mn); sparse multiplication iterates over nonzero terms. Watch coefficient order and integer overflow.

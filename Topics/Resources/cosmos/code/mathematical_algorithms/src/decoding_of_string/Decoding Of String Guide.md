# Decoding Of String

## What it does

Counts ways to decode digit strings using a mapping such as 1→A,…,26→Z. DP at position i adds the one-digit predecessor when the digit is nonzero and the two-digit predecessor when the last two digits are in 10…26. Leading zeroes and modulo requirements need explicit handling.

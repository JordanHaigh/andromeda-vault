# Magic Square

## What it does

Constructs an n×n arrangement of values with equal row, column, and main-diagonal sums. The construction is not one universal algorithm: odd order, doubly-even order, and singly-even order use different placement schemes. The local code’s supported order and validation should be recorded explicitly.

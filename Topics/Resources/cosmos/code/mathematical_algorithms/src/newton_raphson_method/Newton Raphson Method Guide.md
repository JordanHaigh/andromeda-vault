# Newton Raphson Method

## What it does

Finds a root of f(x)=0 by xₙ₊₁=xₙ−f(xₙ)/f′(xₙ). Near a simple root, convergence is typically quadratic. It can fail when the derivative is zero or small, the initial guess is poor, or the function is discontinuous; check residual and iteration limits.

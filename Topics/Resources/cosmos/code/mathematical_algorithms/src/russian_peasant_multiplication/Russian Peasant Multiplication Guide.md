# Russian Peasant Multiplication

## What it does

Multiplies integers by repeatedly halving one operand and doubling the other; add the doubled value whenever the halved operand is odd. It performs O(log n) iterations and uses addition, doubling, and parity tests. Signed values and overflow depend on the implementation’s integer type.

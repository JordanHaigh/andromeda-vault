# Average Stream Numbers

## What it does

Maintains the arithmetic mean of a stream incrementally using count and running sum, or the stable update mean += (x−mean)/count. This requires O(1) state and time per value. Define behavior for an empty stream and consider floating-point error for long or extreme streams.

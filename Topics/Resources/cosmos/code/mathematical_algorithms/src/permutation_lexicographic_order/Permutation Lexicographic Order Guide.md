# Permutation Lexicographic Order

## What it does

Ranks a permutation among lexicographically ordered permutations by counting how many smaller unused symbols could occupy each position, weighted by the factorial number of suffix arrangements. Factorial-number-system arithmetic or a Fenwick tree can make ranking efficient; duplicate symbols require multinomial counts.

# Fibonacci Number

## What it does

Computes Fₙ using F₀=0, F₁=1 and Fₙ=Fₙ₋₁+Fₙ₋₂. Iterative dynamic programming takes O(n) time and O(1) space; fast doubling computes in O(log n) arithmetic operations. The chosen integer type may overflow well before n is large.

# Prime Numbers Of N

## What it does

Generates primes up to n with the Sieve of Eratosthenes: mark multiples beginning at p² for each unmarked p≤√n. It takes O(n log log n) time and O(n) memory; segmented sieves reduce memory for large intervals.

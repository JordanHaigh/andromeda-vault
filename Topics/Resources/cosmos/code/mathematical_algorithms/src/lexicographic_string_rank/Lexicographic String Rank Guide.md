# Lexicographic String Rank

## What it does

Computes the one-based lexicographic rank of a string among permutations of its characters by counting smaller available characters at each position and the permutations of remaining suffixes. Repeated characters require multinomial counts; factorial values may need big integers or modular arithmetic.

# From Inorder And Preorder

## What it does

Reconstructs a binary tree from preorder and inorder traversals with unique values. The next preorder value is the root; its inorder position separates left and right subtrees. A value-to-index map gives O(n) time and space; duplicates make reconstruction ambiguous without extra information.

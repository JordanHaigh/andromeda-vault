# Aa Tree

## What it does

An AA tree is a balanced binary search tree that simulates a 2–3 tree using a level field. Skew removes horizontal left links; split removes consecutive horizontal right links. Search, insertion, and deletion are O(log n) amortized/worst-case under maintained invariants.

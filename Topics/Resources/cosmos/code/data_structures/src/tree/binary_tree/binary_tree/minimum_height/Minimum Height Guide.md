# Minimum Height

## What it does

Computes or constructs a minimum-height binary tree under a stated ordering constraint. For a sorted array, recursively selecting the midpoint yields height O(log n). If the task instead computes an existing tree’s height, traverse levels or recurse and verify whether height counts edges or nodes.

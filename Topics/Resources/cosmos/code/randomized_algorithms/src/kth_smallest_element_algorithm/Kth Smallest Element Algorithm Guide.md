# Kth Smallest Element Algorithm

## What it does

Selects the element of rank k without sorting the full array. Quickselect partitions around a pivot and continues only in the partition containing k, giving expected O(n) time but O(n²) worst case. Median-of-medians offers worst-case linear time with larger constants.

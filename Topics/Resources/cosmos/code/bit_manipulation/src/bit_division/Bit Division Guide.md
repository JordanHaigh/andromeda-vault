# Bit Division

## What it does

Implements integer division using shifts and subtraction to align the divisor’s largest usable multiple with the dividend. Repeatedly subtract aligned powers and accumulate quotient bits in O(word size) iterations. Handle zero divisor, signs, and minimum-integer overflow.

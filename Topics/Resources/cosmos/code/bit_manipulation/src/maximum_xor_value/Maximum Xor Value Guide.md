# Maximum Xor Value

## What it does

Finds a pair or choice maximizing bitwise XOR. A binary trie greedily follows the opposite bit when available, because that sets the current XOR bit to 1. Complexity is O(n·word size); specify whether values are signed or fixed-width unsigned.

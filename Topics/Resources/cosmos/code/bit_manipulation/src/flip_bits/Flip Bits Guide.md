# Flip Bits

## What it does

A bit-flip problem usually minimizes toggles to reach a target pattern or satisfy a constraint. XOR identifies differing positions; the exact greedy/counting rule depends on whether flips affect one bit, a range, or neighboring bits, so follow the local statement and implementation.

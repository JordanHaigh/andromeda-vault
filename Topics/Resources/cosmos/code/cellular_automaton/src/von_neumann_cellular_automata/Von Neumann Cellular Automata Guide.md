# Von Neumann Cellular Automata

## What it does

A cellular automaton using the von Neumann neighborhood: a cell and its four orthogonal neighbors (rather than the eight-cell Moore neighborhood). The precise state-transition rule is variant-specific; document the rule table, boundary conditions, and update model from the implementation.

# Langtons Ant

## What it does

A grid-based ant turns and changes the color/state of its current cell according to a local rule, then moves forward. The classic two-color rule produces an initial chaotic pattern followed by a repeating highway. An unbounded grid or expanding bounds avoid truncating the ant.

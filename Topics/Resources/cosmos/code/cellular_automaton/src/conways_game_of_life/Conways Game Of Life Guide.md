# Conways Game Of Life

## What it does

A two-dimensional cellular automaton where each cell is alive or dead. In the standard rule, a live cell survives with two or three live neighbors; a dead cell becomes live with exactly three. Update all cells from the prior generation simultaneously, using a copy or in-place encoding.

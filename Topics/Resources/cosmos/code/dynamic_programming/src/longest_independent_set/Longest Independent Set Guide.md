# Longest Independent Set

## What it does

For a tree, the maximum independent set is computed by deciding at each node whether to include it (exclude its children) or exclude it (children may be chosen). A postorder traversal computes both states in O(n) time. The general graph problem is NP-hard, so tree structure is essential to this efficient recurrence.

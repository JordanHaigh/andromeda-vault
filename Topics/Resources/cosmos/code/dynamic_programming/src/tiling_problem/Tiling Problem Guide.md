# Tiling Problem

## What it does

Counts or decides ways to tile a board with the piece shapes and placement rules defined by the exercise. Reduce the board into smaller states based on the first uncovered position; the recurrence depends on whether rotations, overlaps, or multiple tile types are allowed. Check the local statement before applying a formula.

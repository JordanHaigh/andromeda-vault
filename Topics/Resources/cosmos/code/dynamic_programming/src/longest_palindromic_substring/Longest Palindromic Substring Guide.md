# Longest Palindromic Substring

## What it does

Finds the longest contiguous substring that reads the same forward and backward. Common solutions expand around every odd/even center in O(n²) time and O(1) space, or use Manacher’s algorithm in O(n). Do not confuse a substring with a non-contiguous subsequence.

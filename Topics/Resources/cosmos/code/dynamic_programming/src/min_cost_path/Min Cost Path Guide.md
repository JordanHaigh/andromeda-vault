# Min Cost Path

## What it does

Computes a minimum-cost route through a grid under the allowed moves. Dynamic programming assigns each cell its own cost plus the minimum predecessor cost. The recurrence and boundary conditions depend on permitted directions and obstacles; a row-wise implementation can use O(columns) memory.

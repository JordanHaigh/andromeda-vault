# Minimum Cost Polygon Triangulation

## What it does

Finds a minimum-weight triangulation of a polygon when the cost of a triangle is defined by its vertices. Interval DP tries each possible middle vertex k and combines the two sub-polygons plus triangle cost. For a convex polygon this is O(n³) time and O(n²) space.

# Shortest Common Supersequence

## What it does

Constructs the shortest sequence containing two input sequences as subsequences. Its length is |a|+|b|−LCS(a,b); a dynamic-programming table for the longest common subsequence gives the shared characters to merge. The standard solution uses O(mn) time and space.

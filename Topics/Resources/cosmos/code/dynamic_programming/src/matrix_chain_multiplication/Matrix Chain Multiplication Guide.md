# Matrix Chain Multiplication

## What it does

Finds the parenthesization of a matrix product that minimizes scalar multiplications; the result is independent of parenthesization, but the cost is not. Interval DP tries each split k using the dimensions of the outer matrices. The classic algorithm is O(n³) time and O(n²) space.

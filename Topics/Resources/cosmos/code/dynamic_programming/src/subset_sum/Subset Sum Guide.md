# Subset Sum

## What it does

Decides whether a subset of non-negative integers totals a target. Boolean DP updates reachable sums in descending order for each item so an item is not reused. The classic complexity is O(n·target) time and O(target) space; this is pseudo-polynomial, and negative values need a different state model.

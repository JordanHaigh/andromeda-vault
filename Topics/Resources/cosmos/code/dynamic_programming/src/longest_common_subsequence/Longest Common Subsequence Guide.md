# Longest Common Subsequence

## What it does

Finds the longest sequence appearing in both inputs in the same relative order, without requiring contiguity. The standard recurrence compares the final characters of prefixes and otherwise takes the larger prefix result. It is O(mn) time; space can be reduced when only the length is needed.

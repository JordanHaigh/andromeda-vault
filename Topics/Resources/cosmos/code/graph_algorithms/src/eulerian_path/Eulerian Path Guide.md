# Eulerian Path

## What it does

An Euler trail uses every edge exactly once. In an undirected connected graph, a circuit requires all non-isolated vertices to have even degree; an open trail requires exactly two odd-degree vertices. Hierholzer’s algorithm constructs one in O(V+E).

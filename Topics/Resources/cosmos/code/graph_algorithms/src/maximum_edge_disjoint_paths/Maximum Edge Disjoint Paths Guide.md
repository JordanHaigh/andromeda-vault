# Maximum Edge Disjoint Paths

## What it does

By Menger’s theorem, the maximum number of edge-disjoint s–t paths equals the minimum number of edges whose removal separates s from t. Assign unit capacity to each edge and compute max flow; extract paths from positive integral flow.

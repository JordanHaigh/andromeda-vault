# Channel Assignment

## What it does

Assigns channels to mutually interfering transmitters, commonly modeled as graph coloring. Vertices represent transmitters and edges represent conflicts; adjacent vertices must receive different channels. Exact minimum coloring is NP-hard, so identify whether this code uses backtracking or a heuristic.

# Prim Minimum Spanning Tree

## What it does

Grows a minimum spanning tree from a start vertex by repeatedly adding the lightest edge crossing from included to excluded vertices. A heap gives O(E log V) for adjacency lists. Negative edge weights are valid; disconnected input requires restarting to form a forest.

# Fleury Algorithm Euler Path

## What it does

Constructs an Euler trail by repeatedly taking an edge that is not a bridge unless no alternative exists, removing it as it is used. This is conceptually simple but slower than Hierholzer’s algorithm. A valid trail requires the appropriate connectivity and odd-degree conditions.

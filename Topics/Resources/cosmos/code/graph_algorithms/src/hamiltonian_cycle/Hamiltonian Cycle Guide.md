# Hamiltonian Cycle

## What it does

Searches for a cycle visiting every vertex exactly once and returning to the start. The general problem is NP-complete; backtracking prunes choices that repeat vertices or violate adjacency, but worst-case work is exponential. Fix the start vertex to avoid equivalent rotations.

# Graph Coloring

## What it does

Assigns colors to vertices so adjacent vertices differ. Minimum coloring is NP-hard in general; greedy orderings provide heuristics, while backtracking can search exactly for small graphs. State whether the code solves a decision problem for k colors or computes a heuristic coloring.

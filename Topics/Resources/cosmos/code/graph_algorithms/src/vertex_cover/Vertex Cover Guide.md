# Vertex Cover

## What it does

A vertex cover is a set of vertices touching every edge. Minimum vertex cover is NP-hard in general graphs; bipartite graphs admit a polynomial-time solution via König’s theorem and maximum matching. The local implementation’s exact variant and guarantees must be checked.

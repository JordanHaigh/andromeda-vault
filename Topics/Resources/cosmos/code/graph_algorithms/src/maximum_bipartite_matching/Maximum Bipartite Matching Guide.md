# Maximum Bipartite Matching

## What it does

Finds a largest set of pairwise non-adjacent edges in a bipartite graph. Augmenting-path algorithms improve a matching by rerouting existing assignments; Hopcroft–Karp groups shortest augmenting paths and runs in O(E√V).

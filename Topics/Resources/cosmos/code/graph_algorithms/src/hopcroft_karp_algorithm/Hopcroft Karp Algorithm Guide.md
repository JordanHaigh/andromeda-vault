# Hopcroft Karp Algorithm

## What it does

Finds maximum matching in a bipartite graph by repeatedly finding a maximal set of vertex-disjoint shortest augmenting paths. BFS layers and DFS augmentations produce O(E√V) complexity. Input must preserve the left/right partition.

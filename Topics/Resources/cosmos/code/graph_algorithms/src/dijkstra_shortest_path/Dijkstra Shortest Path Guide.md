# Dijkstra Shortest Path

## What it does

Computes single-source shortest paths with non-negative edge weights using a min-priority queue and repeated relaxation. With a binary heap it is O((V+E)log V). It is incorrect with negative edges; stale queue entries and overflow need attention.

# Travelling Salesman Mst

## What it does

Uses a minimum spanning tree as a lower bound or approximation ingredient for the travelling-salesperson problem. An MST is not generally a TSP tour; metric assumptions and any doubled-tree/shortcut step determine approximation guarantees. Check precisely which variant the implementation produces.

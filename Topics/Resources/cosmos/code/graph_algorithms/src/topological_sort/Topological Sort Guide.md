# Topological Sort

## What it does

Orders vertices of a directed acyclic graph so every edge u→v places u before v. Kahn’s algorithm repeatedly removes zero-indegree vertices; DFS postorder is another method. O(V+E); fewer than V emitted vertices signal a directed cycle.

# Kruskal Minimum Spanning Tree

## What it does

Sort edges by nondecreasing weight and add an edge only when it joins two distinct components. A disjoint-set union structure makes cycle checks efficient. Complexity is O(E log E); disconnected input yields a minimum spanning forest.

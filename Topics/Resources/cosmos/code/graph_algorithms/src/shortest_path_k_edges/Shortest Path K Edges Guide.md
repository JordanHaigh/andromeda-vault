# Shortest Path K Edges

## What it does

Finds a shortest route constrained to exactly or at most k edges, depending on the implementation. Dynamic programming tracks the best distance after each allowed edge count, which handles negative edges for a fixed bound. Verify the exact constraint and unreachable-state handling.

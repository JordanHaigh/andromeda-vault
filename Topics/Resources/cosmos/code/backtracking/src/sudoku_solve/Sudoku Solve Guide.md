# Sudoku Solve

## What it does

Backtracking chooses an empty cell, tries digits not already present in its row, column, or box, and recurses. Constraint propagation or choosing the cell with the fewest candidates can reduce search substantially. Validate the initial board and define whether multiple solutions are allowed.

# Knight Tour

## What it does

Finds a sequence of legal knight moves visiting every board square exactly once. Backtracking marks visited squares and undoes moves on failure. Warnsdorff’s heuristic tries moves with the fewest onward options first, often finding tours quickly but not serving as a correctness proof.

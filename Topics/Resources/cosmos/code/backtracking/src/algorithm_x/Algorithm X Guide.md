# Algorithm X

## What it does

Knuth’s Algorithm X searches for exact covers by choosing a constraint column, trying each row that satisfies it, covering conflicting constraints, and backtracking. Dancing Links (DLX) is a linked structure that makes cover/uncover operations efficient. Used for Sudoku and tiling exact-cover formulations.

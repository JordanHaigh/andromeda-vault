# N Queen

## What it does

Places n queens on an n×n board so no pair shares a row, column, or diagonal. Backtracking places one queen per row and tracks occupied columns and diagonals, reducing checks to O(1) per candidate. Symmetry can reduce work; total search remains exponential.

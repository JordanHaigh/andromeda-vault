# Quick Sort

## What it does

Quicksort partitions elements around a pivot and recursively sorts each side. Expected time is O(n log n), worst-case O(n²); randomized or median-of-three pivots reduce bad-input risk. In-place partitioning uses O(log n) expected stack space, but stability is not guaranteed.

# Inversion Count

## What it does

Counts pairs i<j where a[i]>a[j]. Merge sort counts cross-inversions while merging: when a right value precedes remaining left values, it contributes their count. O(n log n) time and O(n) auxiliary space; define strict versus non-strict comparison for duplicates.

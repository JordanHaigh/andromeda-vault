# Merge Sort Using Divide And Conquer

## What it does

Merge sort divides the array into halves, recursively sorts each, and merges two sorted runs. It is O(n log n) in all cases, stable when equal items are taken from the left run first, and usually uses O(n) auxiliary memory.

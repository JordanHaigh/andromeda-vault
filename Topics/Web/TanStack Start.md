# TanStack Start

TanStack Start is the full-stack framework entry in the TanStack ecosystem. It combines routing with server-side capabilities; framework APIs and deployment adapters can evolve, so use the current official documentation for runtime, rendering, server functions, and deployment decisions.

## Evaluation checklist

Confirm the deployment target and adapter support; understand server/client module boundaries, request-scoped state, environment variable exposure, authentication, data loading, streaming or hydration behavior, and error handling. Test production builds on the intended runtime, not only the development server. Decide how Start fits with existing APIs and data services rather than coupling domain logic to route modules.

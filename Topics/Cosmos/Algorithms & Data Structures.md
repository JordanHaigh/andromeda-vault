# Algorithms and Data Structures

The Cosmos collection contains implementations and short explanations across algorithms, data structures, computer science theory, and applied computing. This map groups the domains by how they relate, rather than listing every domain as a direct child. Topic notes preserve source explanations where available and link to upstream code when the code itself remains in the original archive.

## Subject clusters

- [[Topics/Cosmos/Algorithm Families]] — Algorithmic problem-solving techniques, from exhaustive search and greedy choices to graph, sequence, and range-query algorithms.
- [[Topics/Cosmos/Data and Theory]] — Core models of information and computation, along with mathematical tools and theoretical bounds.
- [[Topics/Cosmos/Applied Computing]] — Algorithms and structures applied to graphics, machine learning, security, compression, and related fields.
- [[Topics/Cosmos/Systems and Platforms]] — Lower-level computing topics and platform concepts that connect algorithms to real execution environments.
- [[Topics/Cosmos/Programming Practice]] — Language implementations, reusable design ideas, and ways to practice and compare solutions.
